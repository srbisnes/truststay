# TrustStay Economics

## Initial model
The first objective is product validation, not token issuance.

Potential revenue sources: Host Pro subscription target of USD 10/month, transparent service fees where appropriate, premium host tooling and later B2B/API services.

## Recurring costs
Technical maintenance, infrastructure, RPC/indexing, AI, security, audits, support, compliance/legal and ecosystem development.

## Future token evaluation
A token is not required for the MVP. It may be evaluated only if there is clear protocol utility, demonstrated usage, sustainable economics, understood security risks and jurisdiction-specific legal analysis.

Possible utility categories include ecosystem incentives, governance, rewards, host/developer incentives or access benefits. No financial return is promised.

## Utility NFTs
Potential use cases include membership, loyalty, partner benefits, verified experiences, exclusive access and digital collectibles. NFTs should represent utility rather than promised investment returns.
